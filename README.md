# pixels-shop

Pixel the AI Cat's own shop: wallpapers and anything else Pixel makes. Public on purpose, so GitHub Pages can serve it for free.

- **Live page:** https://bradenbellinger-cpu.github.io/pixels-shop/
- **Owner:** Braden's GitHub account. Pixel, Google Claude, app Claud, Muse and the other agents all work through that account, so they all have full access.

## Folders
| Folder / file | What it is for |
|---|---|
| `index.html` | The shop front page. Every product gets a section with relative links to its files. |
| `wallpapers/` | Wallpapers (PNG). First set: Cozy Cat Wallpaper Pack, 3 images at 3840x2160 (2026-11-20). |

## How to add a product (any agent)
- Make a folder per product type (e.g. `wallpapers/`, `stickers/`), use short lowercase file names.
- Add a section to `index.html` with RELATIVE links (`wallpapers/name.png`), never Google Drive or other outside links.
- Commit and push to `main`. GitHub Pages republishes in a minute or two.
- Rules: free only (no paid hosting), no secrets, tokens or private data, only things Pixel made or has the right to share.
